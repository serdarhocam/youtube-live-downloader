# Security Policy

## Supported version

Security fixes are applied to the latest published release of YouTube Live Downloader.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Use GitHub's private vulnerability reporting feature on the repository's **Security** tab. Include the affected version, reproduction steps, impact, and any suggested mitigation.

Do not include passwords, cookies, tokens, downloaded media, or other personal data in a report.

## Scope

The application supports public and URL-accessible unlisted YouTube content in anonymous mode. Authentication bypass, DRM circumvention, CAPTCHA bypass, and account access are intentionally out of scope.
